Scroll Journal

A privacy-first social-media reflection journal for iPhone and iPad.

Scroll Journal helps users move from passive scrolling to intentional reflection. Instead of monitoring applications automatically, it lets users manually record why they opened a platform, how long they spent there, and how their mood changed. The app then turns those entries into clear, locally generated insights.

01 / product context

# Context that screen-time totals miss.

The problem

A number cannot explain an experience.

Social-media screen-time totals explain how long someone used an application, but not why they opened it, what they experienced, or how it affected them. Productive research, messaging, entertainment, comparison, and unintentional scrolling can all appear as the same number.

The solution

Reflection without surveillance.

Scroll Journal captures the context behind social-media use through deliberate manual entry. It does not connect to social-media accounts, read Screen Time data, or continuously monitor the user.

02 / core features

# From individual sessions to useful patterns.

Each feature supports reflection without turning the product into another source of pressure.

01

Intentional session tracking

Record the platform, time spent, reason for opening, mood before and after, and relevant tags for every session.

02

Daily reflections

Write one reflection about how social media affected the day, with support for editing recent reflections.

03

Weekly and monthly insights

Review locally calculated patterns, averages, mood changes, intentional-use trends, and frequently recorded platforms.

04

Creator Library

Save a creator name or handle, optional profile link, topics, a note, and a selected screenshot for future reference.

05

Custom organization

Create custom tags and enter any platform name instead of working from a fixed list.

06

Native iPhone and iPad experience

Adaptive SwiftUI layouts support iPhone and iPad, including portrait and landscape orientations on iPad.

03 / user flows

# Small actions, connected into reflection.

Daily reflection flow
  1. Record a session
  2. Select mood before and after
  3. Add relevant tags
  4. Save the session
  5. Write the daily reflection
  6. Review weekly or monthly patterns
Creator Library flow
  1. Discover an informative creator
  2. Save the creator’s name or handle
  3. Optionally attach a screenshot or link
  4. Revisit the creator later

04 / privacy principles

# Private by design.

Sessions, reflections, tags, creator details, screenshots, and insights remain on the device. Useful patterns do not require a surveillance model.

  • No account or login
  • No advertising
  • No analytics or tracking
  • No third-party SDKs
  • No social-account connection
  • No automatic Screen Time monitoring
  • No external AI service
  • No journal content uploaded to a server
  • Deterministic on-device insights
  • System photo picker for screenshots
  • Optional locally scheduled reminders
  • No backend dependency

05 / design + engineering

# Calm on the surface, deliberate underneath.

Design direction

Quiet, supportive, and recognizably native.

A calm indigo identity, soft gradients, lightly elevated cards, friendly mood controls, compact tags, and clear hierarchy make the experience reflective rather than judgmental. Native Apple interaction patterns keep the interface familiar across iPhone and iPad.

  • Calm indigo visual identity
  • Reflection-focused language
  • Clear information hierarchy
  • Native interaction patterns
Technical implementation

Native SwiftUI with local persistence.

SwiftData manages sessions, reflections, custom tags, and saved creators. PhotosUI provides privacy-preserving screenshot selection, UserNotifications handles optional local reminders, and a deterministic insight engine produces summaries without an external service.

  • Reusable SwiftUI components
  • Adaptive iPhone and iPad layouts
  • Validation, editing, and deletion workflows
  • XCTest coverage for insights and data rules

06 / design decisions

# Three decisions that shaped the product.

01

Context instead of surveillance

Manual entry was intentional: it enables useful reflection without monitoring other applications.

02

Sessions and reflections stay distinct

The data model separates multiple daily scrolling sessions from the broader one-per-day reflection.

03

Insights without external AI

Weekly and monthly observations use transparent, deterministic calculations performed locally.

07 / interface gallery

# The product in use.
